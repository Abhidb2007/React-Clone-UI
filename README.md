# React Clone UI

A responsive React landing page implemented with reusable components, CSS Modules, and modern frontend best practices.

## Installation

1. Install dependencies

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Deploy to Vercel

1. Push your repository to GitHub.
2. In Vercel, import the project.
3. Use the default build command:

```bash
npm run build
```

4. Set the output directory to:

```bash
dist
```
